# 嫦娥七号 · 地月转移科普互动 H5

这是一个基于 **Vue3 + Canvas + 原生 JavaScript** 的青少年航天科普参赛 H5 项目。Vue 只负责 UI 状态、弹窗和响应式布局；轨道绘制、物理积分、碰撞判据和 WASD 操控均由原生 JavaScript 实现。

## 功能概览

- Canvas 绘制写实简约风地球、月球、星空、月球公转轨道。
- 白色虚线绘制：近地停泊圆轨道、月球南极捕获环月轨道。
- 月球围绕地球自西向东公转，探测器需追赶移动目标。
- WASD 操控：W 加速、S 减速、A 左航向修正、D 右航向修正；探测器未脱离地球轨道时，A/D 被锁定。
- 地球/月球引力、向阳侧摄动、月球公转前进方向扰动。
- 强制航天规则提示：逃逸、撞击地球、撞击月球、近月未减速飞越。
- 全局响应式布局，Canvas 展示区域带边框并整体缩放显示，禁用页面默认纵向滚动与触摸滚动，适配 Chrome、Safari、Firefox、Android、iOS。


## 本次定制修改

- 视觉布局：Canvas 展示区改为内嵌边框舞台，并通过视域缩放让地球、月球、探测器和轨道完整呈现。
- 物理规则：近地脱离阈值参考地球低轨圆速度与逃逸速度的比例；近月捕获/飞离判据参考月球低轨圆速度与逃逸速度的比例。
- 底部文案：三栏统一为“脱离地球轨道、轨道偏离原因、月球入轨”。
- 交互规则：停泊段 A/D 锁定，只有脱离地球轨道进入地月转移后才能进行左右航向修正。

npm install

```

```

## 科学与科普说明

本项目是面向青少年的“科普级交互模拟”，不是高精度星历/轨道设计软件。为保证可玩性，画面中天体半径、轨道周期、引力参数和飞行时间经过缩放；但保留以下真实航天规则：

1. 探测器先在近地停泊圆轨道巡航，速度超过近地逃逸阈值后才会脱离近地轨道并进入地月转移。近地逃逸阈值按 11.2 km/s ÷ 7.8 km/s 的真实速度比近似映射。
2. 地月转移不是直线飞行，探测器受地球、月球和太阳摄动影响。
3. 月球在持续公转，探测器需要瞄准月球未来位置，而不是当前月球圆心。
4. 抵达月球附近必须近月制动，否则高速探测器会飞越月球，无法被月球引力捕获。月球入轨判据按 1.63 km/s 低月轨圆速度与 2.38 km/s 月球逃逸速度的真实速度比近似映射。
5. 月球没有稠密大气层，撞击月面无法依靠大气缓冲。
